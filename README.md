# NotyCaption Pro

NotyCaption Pro is an AI-powered caption generation application built around Whisper, Google Colab, and Google Drive.

## Website

https://notycaptiongen.free.nf

## Repository

https://github.com/NotY215/NotyCaption-Official

## Features

- AI subtitle generation
- Whisper-based transcription
- Google Colab GPU processing
- Vocal enhancement
- SRT and ASS subtitle workflows
- Background Drive result tracking
- Automatic completion detection
