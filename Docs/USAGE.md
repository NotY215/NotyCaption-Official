# Usage

## Generate captions

1. Sign in.
2. Upload an audio file.
3. Select the language.
4. Select words per subtitle line.
5. Select the output format.
6. Start caption generation.
7. Run the generated notebook in Google Colab.
8. Keep the application page open while processing.
9. The website tracks the Drive result automatically.
10. The generated captions are displayed when processing finishes.

## Vocal enhancement

1. Upload an audio file.
2. Start vocal enhancement.
3. Run the generated Colab notebook.
4. Wait for the Drive result.
5. The enhanced audio becomes available in the application.
