# Frequently Asked Questions

## Why use Google Colab?

Colab provides GPU-backed processing without requiring a local Whisper or Spleeter installation.

## Does the website need to stay open?

Yes. The website-side tracker needs the application page to remain open while it waits for the Drive result.

## What happens if the Colab tab is closed?

The website tracker is independent of the Colab tab and continues waiting for the result.

## What happens when processing finishes?

The matching Drive result is detected, loaded into the application, the progress reaches 100 percent, and the Colab tab opened by the website is closed.

## Where are generated files stored?

Generated files are uploaded to the authenticated Google Drive account used by the processing notebook.
